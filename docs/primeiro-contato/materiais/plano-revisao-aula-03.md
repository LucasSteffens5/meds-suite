# Plano para revisão — Organizador de documentos

Este plano reúne inconsistências para a aula 3. As avaliações continuam planejadas;
não há resultados registrados.

## Contexto

- Finalidade: ajudar estudantes a encontrar documentos acadêmicos por título e etiqueta.
- Artefato: protótipo v0.1 em desenvolvimento; riscos de busca incorreta e
  apresentação pouco clara.
- Recursos atuais: três dias; até duas horas para avaliação; sem verba adicional.
- Acesso a estudantes e uso real: não confirmado.
- Restrição: não medir notas nem coletar documentos pessoais.
- Próximo passo previsto: definir critérios de clareza e preparar E2.

## Legenda

**Legenda:** ID = identificador; O = objetivo da avaliação; P = propriedade do artefato; E = episódio de avaliação; S = cenário; D = documento. Os números identificam itens, não passos de MEDS.

**Siglas:** MEDS = metodologia para organizar avaliações em DSR; DSR = pesquisa em ciência do design; DSRM = metodologia do projeto DSR; FEDS = estratégia e trajetória das avaliações; DSREMSF = seleção de métodos de avaliação; MuSCoW = prioridades: Must (precisa), Should (deveria), Could (poderia), Would (seria desejável avaliar).
