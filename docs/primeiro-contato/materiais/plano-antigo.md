# Avaliação do organizador — formato antigo fictício

Este é o mesmo caso didático, salvo antes do formato atual do plano. Nenhuma
avaliação foi executada. Estes registros não representam escolhas do leitor.

Protótipo v0.1 de organizador de documentos, produto sociotécnico não crítico para
segurança. Ana e orientador querem decidir melhorias. Há duas semanas de prazo,
até duas horas de Ana, computador próprio, sem verba; acesso a estudantes não
confirmado. “Não quero medir notas nem coletar documentos pessoais.”

O1: identificar falhas para orientar melhorias. O2: julgar correção das buscas nos
cenários sintéticos cobertos. P1: correção Must; P2: clareza Should.

Estratégia inicial: Technical Risk & Efficacy. E1: formativo artificial,
Criteria-Based Evaluation para P1/P2; critérios de clareza pendentes. E2: somativo
artificial, Testing para P1 nos cenários S1–S6 da ficha; versão pós-correções e
protocolo ainda pendentes. Nenhuma conclusão sobre uso real.

Registro fictício preservado: Ana, rodada antiga, disse “Aceito O1, O2, P1 Must,
P2 Should, a estratégia inicial e E1/E2 com esses métodos. Não aceito inferência
de benefício real.”

Fontes: Baskerville, Pries-Heje e Venable (2026), *MEDS: Methodology for Evaluation
in Design Science*, DOI 10.1080/0960085X.2026.2627280; Venable, Pries-Heje e
Baskerville (2016), *FEDS: a Framework for Evaluation in Design Science Research*,
DOI 10.1057/ejis.2014.36.

complementares e quadro de aplicabilidade não foram registrados neste formato.
