# Tutorial MEDS

Este tutorial acompanha a MEDS Suite instalada no Codex. Abra uma conversa na
pasta onde deseja guardar o plano de exemplo e envie:

```text
Use $meds-suite para me ensinar MEDS com um exemplo simples.
```

A suite apresenta um caso fictício, conduz o planejamento e salva o progresso em
`casos/tutorial-meds/plano-meds.md`. Você pode parar a qualquer momento e continuar
em outra conversa com “Continue o tutorial MEDS”. Não precisa abrir este repositório,
localizar materiais ou copiar arquivos.
