# Aula 3 — Revisar e corrigir · 7 minutos

**Meta:** distinguir uma revisão de uma autorização para mudar o plano.

## 1. Prepare a cópia

**Ação:** use uma conversa nova. A entrada é uma versão do mesmo caso com
inconsistências intencionais; não substitui seu plano das aulas anteriores.

```text
Copie docs/primeiro-contato/materiais/plano-revisao-aula-03.md para
 docs/primeiro-contato/pratica/revisao/plano-meds.md somente se o
destino não existir. Não altere a entrada. Calcule o SHA-256 da cópia
antes da revisão e informe o valor.
```

**Confira:** existe uma cópia separada. **SHA-256** é uma impressão digital do
conteúdo: valores iguais antes e depois indicam que os bytes não mudaram.

## 2. Revise sem editar

**Ação:** peça observações, não correções automáticas:

```text
Use $meds-suite para revisar
 docs/primeiro-contato/pratica/revisao/plano-meds.md.
Apresente a revisão somente no chat, sem editar nenhum arquivo.
Para cada observação, indique localização, informação observada,
problema, fundamento, consequência e recomendação. Use os IDs do plano.
```

**Confira:** a revisão relaciona objetivos, propriedades, episódios e limites
da evidência. Propostas novas não viram decisões aceitas.

## 3. Confira a preservação

**Ação:** verifique o arquivo e consulte o gabarito depois de ler a resposta:

```text
Calcule novamente o SHA-256 do arquivo revisado e compare com o
valor anterior. Apenas informe a comparação; não edite o plano.
```

**Confira:** hashes iguais. Leia a [revisão ilustrativa](../referencias/revisao-aula-03.md):
espera-se detectar acessibilidade Must sem cobertura, promessa de benefício em
uso real a partir de buscas artificiais e método aceito sem registro de aceitação.
A revisão pode localizar outras lacunas pertinentes.

## 4. Autorize somente os ajustes escolhidos

**Ação:** se concordar com os três ajustes, envie:

```text
Autorizo corrigir somente esta cópia: registre P5 como Must sem
cobertura, com detalhamento pendente; limite a conclusão de E2 à
correção em S1–S3, removendo a promessa de benefício real; corrija
E3 para proposta não aceita. Registre esta autorização sem apagar
o histórico nem inventar aprovação anterior. Preserve os demais
objetivos, decisões e restrições. Salve no mesmo caminho.
```

**Confira:** P5 continua importante, E3 permanece proposta e nenhuma avaliação
foi realizada. Esta autorização não aceita um método para P5.

## 5. Feche o exercício

**Ação:** solicite uma conferência contextual:

```text
Compare o plano corrigido com a versão anterior: restrições, acesso,
prioridades, critérios e alcance das conclusões. Informe somente
os ajustes autorizados, as pendências e o próximo passo.
```

**Confira:** a redução de escopo continua documentada, sem retirar silenciosamente
prioridades. Compare com o [plano corrigido de referência](../referencias/plano-aula-03-corrigido.md).

Você completou os três fluxos. Para explorar recursos adicionais, escolha um
[exercício opcional](../opcionais.md).
